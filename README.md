# 🚆 Nilsagar Express (সৈয়দপুর ➔ ঢাকা) - Full-Stack Pixel Train Journey Game

বাংলাদেশ রেলওয়ের **৭৬৬ নীলসাগর এক্সপ্রেস** (Saidpur to Dhaka Junction) ট্রেনের বাস্তব সময়সূচী নিয়ে তৈরি একটি ফুল-স্ট্যাক পিক্সেল-আর্ট ট্রেন সিমুলেশন গেম।

---

## 🌟 প্রধান ফিচারসমূহ (Key Features)

1. **বাস্তব সৈয়দপুর থেকে ঢাকা রুট (Authentic 12 Stations)**:
   - **সৈয়দপুর (Saidpur)** ➔ **পার্বতীপুর (Parbatipur)** ➔ **ফুলবাড়ী (Fulbari)** ➔ **বিরামপুর (Birampur)** ➔ **জয়পুরহাট (Joypurhat)** ➔ **আক্কেলপুর (Akkelpur)** ➔ **সান্তাহার (Santahar)** ➔ **নাটোর (Natore)** ➔ **আজিম নগর (Azim Nagar)** ➔ **ঈশ্বরদী বাইপাস (Ishwardi Bypass)** ➔ **জয়দেবপুর (Joydebpur)** ➔ **ঢাকা কমলাপুর (Dhaka)**
   - ট্রেনের প্রতিটি স্টেশনের হলুদ নামফলকে (Station Name Board) বাংলা ও ইংরেজি নাম সুন্দরভাবে প্রদর্শিত হয়।
   - প্ল্যাটফর্মে আগমন, প্রস্থান, যাত্রী ওঠানামা, গার্ডের সবুজ পতাকা নাড়ানো ও হুইসেল সিমুলেশন।

2. **হরাইজন্টাল ওয়াইডস্ক্রিন লেআউট (Horizontal Widescreen Layout)**:
   - ১৬:৯ ওয়াইডস্ক্রিন সিনেমাটিক ডিসপ্লে।
   - উপরে ১২টি স্টেশনের ইন্টারেক্টিভ **Horizontal Route Stepper**, যেখানে ট্রেনের লাইভ লোকেশন ট্র্যাক হয়।
   - ক্যানভাসের নিচে হরাইজন্টাল কন্ট্রোল প্যানেল (Pause, Speed 1x/2x/4x, Next Station, Time, Rain, Sound, Restart)।
   - ফুলস্ক্রিন হরাইজন্টাল মোড সাপোর্ট।

3. **ফুল-স্ট্যাক ব্যাকএন্ড ও এপিআই (Full-Stack Express & Persistent Database)**:
   - **Express.js** ব্যাকএন্ড সার্ভার।
   - ট্রেনের লাইভ স্ট্যাটাস ও ট্রিপ প্রগ্রেস ক্লাউড সেভ (`/api/journey/save`, `/api/journey`)।
   - বাংলাদেশ রেলওয়ের লাইভ সময়সূচী এপিআই (`/api/timetable`)।
   - অনলাইন ই-টিকিট বুকিং কাউন্টার ও পিএনআর (PNR) জেনারেটর (`/api/tickets/book`)।
   - জার্নি হিস্ট্রি ও রেকর্ড সংরক্ষণ (`/api/logs`)।

4. **বাস্তব দৃশ্যপট ও বঙ্গবন্ধু যমুনা রেল সেতু (Scenic Landmarks)**:
   - উত্তরবঙ্গের সবুজ ধানক্ষেত ও গ্রামীন বসতি।
   - সান্তাহার ও নাটোর এলাকার চলনবিল ও কাশফুলের চর।
   - ঈশ্বরদী পার হয়ে বিশাল **বঙ্গবন্ধু যমুনা রেল সেতু** (Jamuna River Bridge truss girder) পারাপার ও নদীর ঢেউয়ের প্রতিবিম্ব।
   - গাজীপুরের শালবনের ছোঁয়া হয়ে ঢাকা কমলাপুরের আইকনিক আমব্রেলা ক্যানোপি ও ঢাকা সিটি স্কাইলাইন।

## 🚀 গেমটি চালু করার নিয়ম (How to Run)

### ১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ২. ফুল-স্ট্যাক সার্ভার চালু করুন:
```bash
npm start
```

### ৩. ব্রাউজারে প্রবেশ করুন:
```
http://nilsagarexp.vercel.app
```

> **নোট**: সার্ভার ছাড়া সরাসরি `index.html` ডাবল ক্লিক করে ফাইল হিসেবেও গেমটি উপভোগ করা যাবে।

## ⌨️ কিবোর্ড শর্টকাট (Controls)

| কি (Key) | কাজ (Action) |
|---|---|
| `Space` / `P` | পজ / চালু করুন (Pause / Resume) |
| `1` / `2` / `4` | গতি নিয়ন্ত্রণ (Speed 1x, 2x, 4x) |
| `N` | পরবর্তী স্টেশনে যান (Skip to Next Station) |
| `T` | দিন / গোধূলি / রাত পরিবর্তন (Time of Day) |
| `W` | বৃষ্টি নিয়ন্ত্রণ (Rain Weather) |
| `M` | সাউন্ড অন / অফ (Sound Mute/Unmute) |
| `R` | ভ্রমণ পুনরায় শুরু করুন (Restart Journey) |
| `F` (চেপে ধরে রাখুন) | ফাস্ট ফরোয়ার্ড (Fast Forward) |
| `D` | ডিবাগ টেলিমেট্রি স্ক্রিন (Debug HUD) |
